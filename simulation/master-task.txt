# MASTER TASK — Build a Historical ISS Pharmaceutical Environmental Exposure Dataset + Interactive Stability Simulator

You are working inside an existing research project on:

**“Interpretable Small-Data ML for Predicting Pharmaceutical Response and Stability Under Long-Duration Spaceflight Conditions.”**

Do NOT treat this as a generic ML project.

The scientific objectives are:

1. Reconstruct the historical environmental exposure experienced by pharmaceutical lots flown in space.
2. Link those exposures to experimentally measured pharmaceutical stability outcomes.
3. Determine whether environmental exposure + molecular properties + formulation can explain pharmaceutical stability.
4. Validate models on drugs not used during training.
5. Eventually estimate stability for additional pharmaceuticals.
6. Build a separate pharmaceutical vulnerability/prioritization ranking model.
7. Build an interactive scientific simulator/UI for exploring these relationships.

# PART 1 — DEFINE THE SCIENTIFIC TARGET

The primary measured outcome should remain based on experimentally measured pharmaceutical stability.

Primary candidate target:

`relative_percent_diff_vs_control`

defined as:

ΔAPI = ((Flight API - Ground API) / Ground API) × 100

Negative values indicate poorer API retention in flight relative to the matched ground control.

Also calculate:

Stability Ratio = (Flight API / Ground API) × 100

Do NOT invent measured outcomes.

Clearly distinguish:

- measured values
- derived values
- reconstructed environmental exposure
- model predictions
- hypothetical simulation outputs

Never label simulated values as experimental observations.
