EDA API Reference & How-To Guide


What Is an API?

An API (Application Programming Interface) allows applications to communicate with each other. The EDA API provides programmatic access to mission telemetry and radiation data through HTTP requests.

You can access data using:

  • The browser interface
  • Command-line tools like curl
  • Programming languages such as Python, JavaScript, or R

Base URL

https://visualization.osdr.nasa.gov/eda/api/

Endpoints

Available Missions
1. /missions/

Returns a list of available missions, title, description and OSDR link.

https://visualization.osdr.nasa.gov/eda/api/missions/
Mission Details
2. /missions/{mission_name}/

Returns name, title, description and OSDR link for a given mission. You can request the details for any mission avaialble on EDA by replacing {mission_name} with RR-1, RR-3, RR-4, RR-5, RR-6, RR-7, RR-8, RR-9, RR-12, RR-17, RR-18, RR-19, RR-23, APEX-03-1, APEX-03-2, APEX-04, VEG-01A, VEG-01B or VEG-01C.

https://visualization.osdr.nasa.gov/eda/api/missions/RR-1/
Telemetry data
3. /missions/{mission_name}/telemetry_data/

Returns time-series data for temperature, relative humidity and CO2 measurements (ISS and ground control) for a given mission.

https://visualization.osdr.nasa.gov/eda/api/missions/RR-1/telemetry_data/
4. /missions/{mission_name}/{telemetry_measurement}/

Returns time-series data for a specific telemetry measurement (ISS and ground control). You can replace {telemetry_measurement} with temperature, humidity or co2.

https://visualization.osdr.nasa.gov/eda//api/missions/RR-1/temperature/
https://visualization.osdr.nasa.gov/eda//api/missions/RR-3/co2/
https://visualization.osdr.nasa.gov/eda//api/missions/RR-5/humidity/
5. /missions/{mission_name}/{telemetry_measurement}/iss/

Returns time-series data for a specific telemetry measurement collected on the ISS.

https://visualization.osdr.nasa.gov/eda/api/missions/RR-6/temperature/iss/
6. /missions/{mission_name}/{telemetry_measurement}/ground/

Returns time-series data for a specific telemetry measurement collected on ground control.

https://visualization.osdr.nasa.gov/eda/api/missions/RR-6/temperature/ground/
Radiation data
7. /missions/{mission_name}/radiation_data/

Returns time-series data for Galactic Cosmic Ray (GCR), South Atlantic Anomaly (SAA) and Total Radiation measurements for a given mission.

https://visualization.osdr.nasa.gov/eda/api/missions/RR-1/radiation_data/
8. /missions/{mission_name}/{radiation_measurement}/

Returns time-series data for a specific radiation measurement. You can replace {radiation_measurement} with gcr, saa or total.

https://visualization.osdr.nasa.gov/eda/api/missions/RR-9/gcr/
https://visualization.osdr.nasa.gov/eda/api/missions/RR-9/saa/
https://visualization.osdr.nasa.gov/eda/api/missions/RR-9/total/

Filtering with Query Parameters

You can filter telemetry or radiation data by date range using the start and end parameters. Both parameters expect timestamps in ISO 8601 format (YYYY-MM-DDTHH:MM:SSZ).

Examples:
https://visualization.osdr.nasa.gov/eda/api/missions/RR-1/temperature/?start=2014-09-21T00:00:00Z&end=2014-10-20T00:00:00Z
https://visualization.osdr.nasa.gov/eda//api/missions/RR-1/temperature/?start=2014-09-21T00:00:00Z
https://visualization.osdr.nasa.gov/eda//api/missions/RR-1/temperature/?end=2014-09-21T21:29:00Z

If no start or end is provided, the full dataset is returned.

How to Use the API

Using the Browser UI

Visit any endpoint (e.g. https://visualization.osdr.nasa.gov/eda/api/missions/) in your browser to access the user interface. It supports pagination, search, and interactive requests.

Using Python (requests) 
import requests

url = "https://visualization.osdr.nasa.gov/eda/api/missions/"
response = requests.get(url)
data = response.json()
print(data["data"][:5])
Using JavaScript (Fetch API) 
const url = "https://visualization.osdr.nasa.gov/eda/api/missions/";

fetch(url)
  .then(res => res.json())
  .then(data => console.log("EDA missions:", data.data))
  .catch(err => console.error("Error:", err));
Using curl 
curl https://visualization.osdr.nasa.gov/eda/api/missions/
Using R 
library(httr)
library(jsonlite)

url <- "https://visualization.osdr.nasa.gov/eda/api/missions/"
res <- GET(url)
data <- fromJSON(content(res, "text"))
print(head(data$data))
